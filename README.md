# 🛡️ CyberSec Academy & E-Learning Platform

Welcome to **CyberSec Academy**, a modern, security-focused educational web platform designed for ethical hackers, cybersecurity enthusiasts, and developers. Built with a sleek cyber-neon aesthetic, it offers structured offensive security courses, penetration testing labs, and practical modules.

---

## 🚀 Features

- **Cyber-Neon UI / UX:** Immersive dark-themed glassmorphism design with animated glowing backgrounds and responsive layouts.
- **Secure Authentication:** Custom-styled login and signup interfaces with password visibility toggles and session options.
- **Curated Course Catalog:** Detailed pricing, banners, and module breakdowns for high-demand cybersecurity topics.
- **Mobile & Desktop Friendly:** Fully optimized grid views that adapt seamlessly across devices.
